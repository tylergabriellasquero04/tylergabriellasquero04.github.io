## Introduction

In web development, HTML and CSS are two of the main tools for creating websites. They allow developers to create unique websites in many different ways. However, building websites from scratch can become time-consuming, especially when working on more complex projects. This process can be made easier through the use of UI frameworks such as Bootstrap 5. Although learning Bootstrap can be confusing at first, I believe it’s worth learning because it makes web development easier and saves time. 
 

## Why Use Bootstrap 5?

A key advantage of using Bootstrap 5 is that it provides components and classes that developers can use without spending too much time writing all the styling themselves. For example, Bootstrap makes it easier to create navigation bars, buttons, and layouts using containers, rows, and columns. Another useful feature of Bootstrap 5 is responsive design, which helps websites adapt to different screen sizes. 

According to the official Bootstrap 5 documentation, Bootstrap is designed to help developers build responsive websites using its existing components and layout features. Although this can be done with HTML and CSS, the convenient thing about Bootstrap is that it allows developers to create their websites more efficiently without having to start from scratch.


## My Experience with Bootstrap 5

Before doing the experiences and assignments for ICS 314 involving Bootstrap 5, I had no prior knowledge of this UI framework or CSS, although I had heard of HTML before. However, going through the Bootstrap 5 assignments helped me become more familiar with these tools. These assignments allowed me to recreate websites such as Island Snow, Murphy’s, and Banyans. One assignment I particularly enjoyed was choosing a website to recreate on my own. This was a fun and personal experience for me because I chose to recreate the official Super Smash Bros. website.

An important thing I noticed while going through these assignments was how useful Bootstrap’s layout system was. Using containers, rows, and columns allowed me to better organize different parts of a webpage without having to write as much CSS. However, I ran into a few challenges, especially when trying to make my websites look similar to the provided examples. For instance, when recreating Murphy’s website, I had to make adjustments to the spacing and alignment of certain parts to make it as close as possible to the given example. Additionally, I had issues with images not loading properly in some of my projects. 

Although these problems were frustrating, to say the least, they helped me become more familiar with Bootstrap and understand how it works alongside HTML and CSS. I also learned that Bootstrap doesn’t automatically make everything look perfect, and sometimes you have to make adjustments yourself. 


## Software Enginnering Benefits

Another thing I noticed about UI frameworks is that they can make working on larger projects much easier. Bootstrap provides tools such as reusable components and consistent styling, which can be useful when multiple developers are working on the same website. Instead of each person creating their own styles for similar elements, they can use the same Bootstrap classes to keep things consistent.

Additionally, this can make website maintenance easier for developers since they don’t have to keep writing the same CSS. However, some downsides to Bootstrap are that it takes time to learn the different classes, and customizing certain components can at times be difficult. Having a good understanding of HTML and CSS is important, even when using a framework. 


## Closing Thoughts

Overall, despite the challenges, learning UI frameworks like Bootstrap 5 is worth it. Through my experience in ICS 314, I’ve learned that Bootstrap can make web development more efficient, especially when creating layouts and organizing different sections of a website. Despite the struggles I had in certain parts of my assignments, I feel like I’ve gotten more comfortable using Bootstrap through practice. In the end, I think knowing how to utilize HTML and CSS along with UI frameworks is a useful skill to have in web development as well as in software engineering.
