## Coding/Programming Experiences Pre-College
Before TypeScript, I remember my first time experiencing, or rather, playing with code was about 10 years ago while I was homeschooled. I recall my older brother asking me to practice coding on Codecademy. After that, when I first started attending Waipahu High School in 2019, I was reintroduced to coding during my Freshman year. During that time, I don’t recall what coding language I was working in. I didn’t return to working with code in high school until my Senior year. At that time, I do recall working in Java or talking about Java in my Computer Science work-based learning class. I also recall the mention of other programming languages such as JavaScript, Python, C, and C++. 


## Coding/Programming Experiences During College
When it comes to coding during my college career, in my 2nd semester (Spring 2024) attending UH Manoa, which was also my 2nd semester as a Freshman here at UHM, I returned to Java through ICS 111. My prior knowledge of other programming languages besides Java continued to grow through the use of Python in my 3rd semester (Fall 2024, 1st semester as a sophomore) here at UHM by taking ICS 141, and last semester (Spring 2026, 2nd semester as a junior) through the use of C and C++ by taking ICS 212. If I were to choose which programming language is my favorite, then I would say Java.



## Initial Thoughts on TypeScript
I don’t recall hearing about TypeScript before taking ICS 314. However, when I first got into TypeScript during week 2 of the course, I noticed something similar between TypeScript and another programming language, JavaScript. Putting 2 and 2 together, I said to myself, “TypeScript and JavaScript that feels ironic. It was nice completing the JavaScript and TypeScript experiences back-to-back for my ICS 314 class. I was able to notice the coding similarities between JavaScript and TypeScript. However, there were a lot of new programming concepts that I learned through TypeScript. From a software engineer’s perspective, I would say TypeScript is a very useful language. Not just from a programming standpoint but from a teaching standpoint. It’s a great language to program in and a language that should be taught and used in more computer science courses. This leads into my next point. 



## A WODerful Time
As mentioned in a previous paragraph, I said my favorite programming language is Java. I think I'll feel the same way about TypeScript as I did with Java. For the most part, the practice WODs we have done in the past few weeks in ICS 314 are good ways for me to slowly get into liking TypeScript the way I did with Java back in my ICS 111 class. The WODs were also a good way for me to see what it's like to program in a new programming language that is unfamiliar to me. Even though there were a lot of practice WODs, there were still good ways to gain more knowledge of TypeScript and to also code, or rather speak, in TypeScript.  


## Conclusion
Overall, despite not recalling or having prior knowledge of TypeScript, I believe TypeScript and I will get along. Once I get accustomed to TypeScript, I feel the same way about it as I do with Java. Hopefully, after taking ICS 314, I will end up using TypeScript in projects in my future career.
