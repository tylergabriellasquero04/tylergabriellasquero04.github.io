## Importance of Coding Standards

Personally, I feel coding standards play a tremendous part in software engineering and programming in general. Coding standards are essential in programming in many ways. Probably the most important is learning a programming language like Java, Python, and so on. Coding standards can guide a new programmer or software engineer in the world of programming. If a programmer comes into programming blind, then utilizing coding standards can help shed some light on their journey through programming. I feel like most software engineers today dealt with coding standards when they first started programming, and they probably continuously use them. From my perspective, coding standards are like that childhood friend you met in preschool and kindergarten and have been friends with ever since then. For a programmer, coding standards are that childhood friend who’s always with you wherever you go. 



## Experience with ESLint in VSCode

My experience working with ESLint in VSCode started kind of 50-50. Installing extensions like ESLint in VSCode was pretty straightforward. However, trying to run the commands for ESLint via the VSCode terminal was rough at the start. There were a few times I encountered some trouble trying to enable ESLint in some of my files that needed the use of ESLint for ICS 314. However, after a few trials and going through the WODs, I was able to get over those hurdles, and now I like using ESLint in VSCode. Personally, VSCode was already great at tracking errors in my code, but I feel that ESLint is a great backup tool for checking for errors in code or in programs in general. ESLint is that two-factor authentication in programming because using it is a way for a programmer to check that their code runs fine and there are no stylistic errors. 


## Past Experiences with VSCode and other IDEs

Working with VSCode again felt very refreshing. Prior to having to use VSCode for ICS 314, I’ve used VSCode for previous ICS courses. The first time was for ICS 211 during the summer of 2024. During this course, I used VSCode for homework assignments, and the programming language we used was Java. The second time I used VSCode in an ICS course was during fall 2024 in my ICS 141 class. Like with ICS 211, I used VSCode for the same reason, which was completing homework assignments. However, instead of using Java as our programming language, we used Python in this course. Outside of VSCode, another IDE that I used during my college career was Eclipse. I utilized Eclipse when I took ICS 111 back in Spring 2024. Like with ICS 211, ICS 111 also used Java, and if I recall correctly, ICS 111 also had coding standards that needed to be adhered to.

## Summary

In conclusion, coding standards are important for software engineers and programming. It is not meant to deter a programmer, but to guide them. Without coding standards, programming as a whole may be a hassle today. However, since coding standards exist, programming feels less stressful and more relaxed.
